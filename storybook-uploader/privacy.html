Privacy Policy

Last updated: October 23, 2026

Storybook Uploader ("the app") is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

What the app accesses

With the owner's permission through Google sign-in, the app uses the YouTube Data API to upload videos to the owner's channel, set their titles, descriptions, tags and thumbnails, change their visibility, and read the channel's name to confirm which channel is signed in.

What the app stores

The app stores the Google sign-in token on the owner's own computer or server so it can upload without signing in each time. It does not collect, store or process data about viewers or any other person.

Sharing

The app does not sell, share or transfer any data to anyone. Data is sent only to Google, to perform the actions described above.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it makes the stored token stop working.
